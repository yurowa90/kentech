# 정책0 호스트 지방채 진단과 G 후보 측정

측정 기준: `2bda709` (`a7a6005` 뒤 1커밋), 브랜치 `wip/q8-e2b`. Node v24.21.0. 금액은 게임 억, 점수는 36달 최종값이다. 씨앗 common은 `bots-strategy-common`이다. 호스트는 기준선+5후보의 36판(7,776 도시·월), bots36은 기준선+호스트 통과 후보의 12회(23,328 도시·월)를 측정한다. 후보 순위·추천·채택은 하지 않는다. 정책0 호스트는 여섯 도시 모두 balanced 건설만 제출하는 경로이며, bots36의 base 열은 주변 도시의 전략이 회전하고 `cooperate`가 연계선을 제출하는 별도 경로다. base 결과를 호스트 축 D 통과로 대체하지 않는다.

## 원인

정책0 호스트의 직접 원인은 **초기 설비·연구소 투자 뒤 지속되는 화성·오산의 전기 운영 적자**다. beta·gamma·epsilon은 마지막 신설 뒤에도 총판매액보다 연료비가 계속 커서 지원금·세금에서 서비스·연구·이자를 뺀 잔액으로 메우지 못한다. 판매 기준은 자기 원가가 아니라 다른 도시의 공급량 가중 평균 원가×1.02다. 따라서 LNG·환율의 높고 낮음은 자기 연료비뿐 아니라 상대 원가와 판매액도 바꾼다. alpha의 높은 국제 연료 지수에서도 화성의 판매 증가가 더 커 적자가 작았으며, common은 초기 건설비가 작고 사건 보너스가 많았다. 부채 주의·위기 때 건설 보류가 켜져도 이미 지은 연구소의 운영비는 남고, AI가 제안한 증세·서비스 축소는 이 정책0 실험 계약에서 적용되지 않는다. beta 첫 초과 29월은 주민세·산업세 49.906억에서 전기 적자 29.595억, 서비스 40.882억, 연구 6억, 이자 1.510억 등을 지불해 현금이 28.081억 감소했다. D-74 계통 보충과 이웃 구매는 이 호스트 경로에서 0 또는 부동소수 잔차다. 연초 한도 갱신은 작은 추가 영향이며 초과 발생월의 직접 원인은 누적 현금 감소다. 이 설명은 관측 분해이며 특정 국제 사건 하나를 제거한 인과 실험은 아니다.

## 계약·재현

- `q8-host-debt.js` 원문에서 CLI 루프만 제외하고 `runSeed`를 그대로 호출했다. 계획·정책·정산 순서, 6도시, 36달, balanced, 정책0를 유지했다. AI의 연구 요청·연계선 제안·경제 정책을 추가 제출하지 않았다.
- VM의 `AI.plan`, `monthStep`, `C.run`을 관찰하고 `gridSupply` 직후 실제 비용만 읽었다. 반사실 CO₂ 호출은 제외했다. 후보마다 새 VM을 만들며 G 등급·기존값을 단언한 뒤 해당 params의 `.v` 하나만 바꿨다.
- 순차 자식 프로세스 한 개만 계산한다. 시작 전 및 실행 중 10초마다 1분 부하를 확인하고 150 초과 시 SIGSTOP, 이하로 내려오면 재개한다.
- 원장 순차익 `rev.tariff`와 총판매 `tariffGross`를 함께 보존했다. 총액 표에서는 상계된 원가를 복원하고, `cost.fuel`에 포함된 계통비를 분리했다. 이웃 구매·연구·이자는 별도다. 반올림 열까지 포함하여 수입−비용=현금 증감이 맞는지 단언했다.
- `revYear`는 연초 직전 12달 주민세·산업세·시설세입·지원금으로 갱신한다. 전기판매·거래·사건 보너스는 포함하지 않는다. 한도 계수 0.88, 주의 문턱 revYear×0.55, 위기 문턱과 점수식은 그대로다.
