## 6. 산업 세금 탄력의 원인 분리

같은 lib 근사 입력에서 주민 이동·총량 성장을 끄고 κ_ind=.05로 600달을 돌렸다. 국제 지수까지 고정하면 마지막25달 몫 변화0으로 실제 수렴한다.

| 실험 | 장기 산업 몫 변화 |
|---|---:|
| 현재 F07 식 | +0.577772% |
| 이전 price 가중 | +0.487935% |
| 산업세 평균에서 자기 제외 | +0.695088% |

현재 대표 도시의 가중 합 .78845, 정규화된 tax 가중 .0887818이다. 초기 매력 변화의 직접 로짓 예측은 +.657093%, 토지 포화 되먹임을 포함한 고정점은 +.577772%다. 자기 포함은 과대 효과의 원인이 아니고 자기 제외는 효과를 더 키운다. 정규화도 일부만 설명한다. 명시된 β_ind=.08·taxPoints=10·가중/로짓 식과 REF의 +.24% 검산값은 양립하지 않는다. 삭제된 원 실험이 없어 어떤 당시 임시값이 +.24%를 만들었는지는 확정할 수 없다.

처리: M 계수나 세금 식을 임의로 반으로 줄이지 않았다. betaIndReal note에 미재현 사실과 실제 정상상태 값을 적고 재현 검사를 추가했다. REF §2.7·4.6의 정정 문안: “현재 R2의 명시된 식으로는 약 +.58%; +.24%는 재현되지 않으며, 고용 탄력 목표 .22~.44%와의 재보정은 별도 근거 결정이 필요하다.”

recal 07·08의 수렴 오라클은 intl의 환율·해운·수출 무작위 걷기를 끄지 않는다. 09는 미반올림 상태 Aeff로 로짓을 계산하면 현실/게임 이동 잔차 .3591/.3067명으로 정수 반올림 허용1명 안이다. 원 recal 검사는 지시대로 수정하지 않았다.

## 9. 화면 계약 필드

- `report.flows.pop[i].{from,to,n,why,whyGrade}`: 이유와 등급 분리. 산업 흐름도 whyGrade 제공.
- `report.groups[id].{why,whyGrade}`: 도시 지지 변화 문구·등급. 기존 `approvalChangeCause`, `lowestGroupDissatisfaction` 의미 분리 유지.
- `publicView(S).econ.speeds.{eduSpeed,monthsPerTurn,note}`: 4.4·4.4·이동 시간 문구.
- `report.cities[id].bioCo2`: 국가 총량 밖 바이오 CO₂ 정보.
- `report.fiscal[id].{debtRatio,debtStage}`: 예산 환산 채무비율과 ok/warn/crisis. 기존 debtOver/debtCap도 유지.
- `report.cities[id].co2Intensity`: 지연된 소비 탄소집약도.
- `score.aggregation.{name,formula,weights}`: 균형 점수 이름·기하평균식·최종 가중.
