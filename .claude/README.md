# Claude 작업 문서 구조

이 저장소를 Claude Code로 작업할 때, 대화가 길어져 컨텍스트가 압축되거나 세션이 바뀌어도 방향과 진행 상황이 사라지지 않도록 문서를 층으로 나눴다. Claude Code의 권장 방식(프로젝트 메모리 CLAUDE.md, 필요할 때만 불러오는 스킬)을 따른다.

| 층 | 파일 | 언제 읽히나 | 담는 것 | 바뀌는 빈도 |
|---|---|---|---|---|
| 1. 프로젝트 기억 | `/CLAUDE.md` | 세션 시작마다 자동, 압축 뒤에도 다시 | 사용자와 일하는 방식, 저장소 규칙, 깨면 검사가 실패하는 계약, 검사 판정 기준 | 드물게 |
| 2. 진행 상황 | `/docs/PROGRESS.md` | CLAUDE.md가 `@docs/PROGRESS.md`로 함께 불러옴 | 사용자가 정한 방향(원문 요지), PR 현황, 현재 상태, 다음 단계, 되돌리면 안 되는 결정 | 작업 단계마다 |
| 2-1. 결정 로그 | `/docs/DECISIONS.md` | CLAUDE.md가 `@docs/DECISIONS.md`로 함께 불러옴 | 결정마다 맥락·대안·근거·결과·상태(ADR 형식). 바꿀 때는 새 항목 추가 | 결정할 때마다 |
| 3. 절차(스킬) | `.claude/skills/<이름>/SKILL.md` | 설명(description)이 맞는 일을 할 때만 | 반복 절차와 체크리스트 | 절차가 바뀔 때 |

## 스킬
- `kcp-run-tests`: 검사 14종과 모형 검산을 돌리고 기준선과 비교하는 법(샌드박스의 폰트 인증서 오류 걸러 내기 포함).
- `kcp-ui-skin`: 화면 시안 v2의 오마주 스킨·장면을 만드는 계약과 CSS 규칙.
- `kcp-handoff`: 압축·세션 전환 전에 PROGRESS.md를 갱신하는 법.

## 쓰는 법
- 새 세션에서는 "PROGRESS.md 보고 이어서 해줘"라고만 해도 된다.
- 오래 지킬 규칙은 CLAUDE.md에, 이번 작업의 상태는 PROGRESS.md에 둔다. CLAUDE.md가 길어지면 세부는 스킬로 옮긴다.
- 사용자 선호나 결정이 바뀌면 해당 줄을 고친다. 지난 결정을 지우기보다 근거와 함께 바꾼다.
