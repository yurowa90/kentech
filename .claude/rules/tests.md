# 검사 규칙

- 판정: 단언 실패·콘솔 error/warning·페이지 오류·가로 스크롤·예외가 모두 0이어야 통과. 클라우드 샌드박스에서는 구글 폰트 인증서 오류(`ERR_CERT_AUTHORITY_INVALID`)만 예외로 본다. 맥 로컬에서는 이 오류가 나지 않는다.
- 맥 로컬 환경: `tests/.venv`(uv), Playwright 1.63 + chromium-headless-shell 1243. 클라우드는 1.56 고정. 서버는 반드시 `tests/srv.py`(연결 대기열 256). 기본 `http.server`는 대기열이 5라 병렬 검사에서 연결을 끊는다.
- 검사를 느슨하게 고칠 때(허용 오차, 대상 제외)는 명세 근거 절을 주석으로 달고 보고한다. 기대값을 구현에 맞춰 베끼지 않는다. 검사와 구현이 어긋나면 명세를 기준으로 판정한다.
- Playwright 함정: 문자열 식의 결과가 함수면 자동 호출된다(`KCP.on(...)`은 `() => { KCP.on(...); }`로 감싼다). 폭이 0인 요소는 보이지 않는 것으로 판정된다(숨김은 hidden 속성과 계산된 display로 확인). 닫힌 `<select>`의 키 동작은 운영체제마다 다르다(`select_option` 사용). 저장 확인은 250ms 대기 저장 때문에 400ms 뒤에 한다.
- 검사 결과 파일은 `tests/results/`(git 무시). 검사 작성은 구현과 다른 세션이 명세만 보고 한다.
