## 2. 사용자 요구(원문 요지)
- 재정: 해마다 국가 재정지원금 + 산업·주민 수에 따른 세금.
- 살기 좋고 편할수록 주민 증가, 산업 기반·자원 수급이 좋으면 산업 발전.
- 지역 전체 주민·산업 총량은 정해져 있고 해마다 조금 증가, 도시마다 좋은 곳으로 이전(기업도 이전 희망).
- Democracy·심시티·문명 인사이트, 전체적으로 경쟁형 타이쿤, 해외 수입·수출·국제 물류·통상 약간.
- 1턴 = 1달.
- 일하는 방식: 총괄이 나누고 → Sol/Astra 작업 → Opus 독립 검토. 혼자 하지 말 것.
- 답은 한국어로, 학술적·비판적으로, 출처·근거 등급(O/P/M/G).

## 3. 설계 SPEC(요약 — 원문 docs/ECON-SPEC.md, 자료 docs/ECON-DATA.md)
1. 시간: 1턴 = 1달(12/24/36턴, 로비에서 고름, 기본 12). 1월마다 재정지원금. 달마다 대표 7일 전력 운영을 달 일수/7배로 환산.
2. 도시 상태: pop(주민, 실제 규모), ind(종사자), cash(에너지·산업 계정, 음수면 지방채, 한도 연 세입 50%), 세율 단계 taxRes·taxInd(−2..+2), 공공서비스 단계, 기업 보조.
3. 살기 좋음 L: 전력 신뢰, 전기요금, 대기질, 일자리, 공공서비스·교육(대학), 세금, 혼잡. 산업 매력 A: 전력 신뢰(큼), 단가, 재생 비중(RE100), 인력, 대학, 물류(항만), 세율, 보조, 용지.
4. 이동: 목표 몫 s* = 현재 몫 × exp(β·(L−L̄)/10) 정규화, 달마다 κ만큼 다가감(주민 0.01, 산업 0.005). 합 보존. 기업 이전 희망 사건(조건 제시 → 도시 제안 → 진행자 결정).
5. 재정: 세입 = 재정지원금(기본 + 1인당 + 재정자립도 균형분) + 주민세 + 산업세 × 산출 지수 + 전력 거래. 세출 = 건설·연료·운영·서비스·보조·이자.
6. 순환 고리: pop·ind 배수만큼 마을·산업 전력 수요가 바뀜(build.js `MODS.demandRes`, `MODS.demandInd` — 이미 구현).
7. 국제: LNG 가격·환율·수출 수요·해운 지수(씨앗 난수, 평균 회귀), 사건(해운 차질, LNG 급등, 수출 호황, EU CBAM — 철강 수출 도시 감점), 연료비 배수 `MODS.fuelMul`(이미 구현).
8. Democracy: 정책 슬라이더, 지연 효과(달마다 25%), 집단 6개(직장인·청년·노년·기업·농어민·환경단체) 만족 → 지지율, 12턴마다 평가.
9. 점수: 주민·산업 증가, 현금, 1인당 CO₂, 지지율, 정전 → 0–100 가중 합, 순위표.

## 4. 진행 상황(이 브랜치, 2026-10-03 클라우드 세션 기준)
끝남
- 달 턴 구조: `newState(room, region, now, ids, {turns: 12|24|36})` → `S.rounds`(월·연·계절), `roundsOf(S)`, 로비 '게임 길이' 버튼(기본 12달, '계절 4라운드'는 예전 방식), 턴 이름 "2027년 3월 (3/12턴)".
- 경제 엔진 `ui/econ.js`·`ui/econ-data.js`(하위 에이전트 구현, 리드 연결): 1월 재정지원금(재정자립도 균형분), 달마다 주민세·산업세·전기요금 수입, 공공서비스·보조·이자, 지방채 한도, 이주·기업 이전(총량 보존), 집단 6개 만족 → 지지율, 국제 지수(LNG·환율·수출·해운)와 사건(CBAM 등), 기업 이전 희망 제안.
- 리그 연결(`ui/league-core.js`): 경제 모드 예산 = 이번 달 시작 현금 기준(`budget = cash + committed + tieAt − tieShare + 이번 달 사건 지원금`), `run()` 끝에 `econMonth()`(대표 7일 × 달 일수/7로 환산해 `monthStep`), 첫 달에 '정상 도시' 기준으로 `calibrate`, `modsFor`에 수요 배수(주민·산업)와 연료비 배수(국제), 요청 `econ`(세율·서비스·보조), 기업 제안은 만료 달에 조건 충족 도시 중 산업 매력 1위로 결정, 공개 상태 `econ`(도시 요약·국제 지수·제안·점수).
- 시작값: 2025 공식 통계(인구·종사자·재정자립도·노년 비중, 검색 요약 확인 O*)와 추정(G) — `docs/ECON-DATA.md`.
- 검사: `tests/league/test-econ.js`(엔진 불변 조건 697,020개 통과), `tests/league/econint.py`(경제 모드 12달 통합 71개 통과), 리그 rules·e2e·e2e2·e2e3 문제 0.

알려진 문제(다음 담당이 먼저 볼 것)
1. 정전 100%인 도시도 지지율이 거의 안 떨어지고(12달 동안 53→56) 인구 감소가 연 1% 미만 — 화면에서 원인·결과가 안 보인다. 반대로 자료 조사는 지금 β가 현실보다 3~4배 빠르다고 함(β_pop ≈ 0.08 권장). '현실 속도'와 '수업에서 보이는 속도'를 나눠 정할 것(예: 현실 계수 × 교육용 배속, 화면에 배속 표시).
2. 점수에서 현금 부분이 '쓰지 않고 쌓기'를 보상한다(투자 안 한 당진이 한때 평택보다 높음). 현금은 부채 감점만, 또는 '투자 효율'로 바꿀 것.
3. 달마다 순수입이 커서(도시당 월 +30~60억) 1년이면 시작 예산의 2배 — 타이쿤 성장감은 좋지만 연계선·연구 비용 대비 너무 쉬울 수 있음. 밸런스 실행으로 확인.
4. 사건이 매달 1~2개 나오는 빈도(계절 라운드 기준)를 달 턴에 맞게 낮출 것.
5. 독립 검토(Opus)가 클라우드 세션에서 진행 중이었다 — 결과는 이 문서 끝 '독립 검토 결과'에 덧붙여 올린다(없으면 맥에서 다시 돌릴 것).

남은 일(권장 순서)
1. 밸런스(위 1~4) → 자동 실행(전략 봇: 디젤 몰빵, 재생+저장, 연계선 협력, 아무것도 안 함, 세율 최저·최고)으로 36달 결과표.
2. 팀 화면 '도시' 서랍: 주민·종사자·현금·지지율, 집단 막대, 세율·서비스·보조 슬라이더(요청 `econ`), 지난달 세입·세출, 이주 뉴스, "왜?" 한 줄, 기업 제안 조건 대비 우리 상태.
3. 진행자 화면: 순위표(점수 부분별), 광역 지도 위 이주 화살표, 국제 지수·뉴스 띠.
4. 문서 D-57, README, PROGRESS. 회귀 14종.
