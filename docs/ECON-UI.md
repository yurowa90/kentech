# 경제 층 화면 명세 v1(2026-10-03, 총괄)

경제 모드(달 턴, `publicView(S).econ`이 있을 때)에서만 보이는 화면 두 가지. 계절 4라운드 모드에서는 아무것도 바뀌지 않는다. 구현(`ui/league.js`·`ui/league.css`)과 검사(`tests/league/econui.py`)는 서로 다른 세션이 이 문서만 보고 만든다. 엔진 계약은 `docs/ECON-BALANCE.md` '계약'을 따른다(공개 상태 `V.econ`에 도시 요약·국제 지수·제안·점수·`eduSpeed`, 지난달 보고서 `V.econ`의 해당 필드 — 실제 이름은 `ui/league-core.js`의 `econView`를 읽어 확인).

공통
- 기존 남색 v2 UI 토큰과 `lg-` 접두어 CSS를 쓴다. 밝은·어두운 두 벌. 390×844에서 가로 스크롤 없음, 조작 44px, 글자 대비 4.5 이상, 콘솔 error·warning 0.
- 도시 이름은 자료에서 읽는다(D-58). 숫자에는 단위(억·명·%). 공식 통계에서 온 시작값은 `tag-official`, 게임 가정 수치(배속 등)는 'G' 표시나 `tag-mine`.
- 모든 동적 문자열은 `KCP.esc`.
- 고교생이 읽는 짧은 한국어. "왜?" 한 줄은 엔진의 `why`·원인 문구를 그대로 쓴다.

## U1. 팀 화면 '도시' 서랍
- 아래 막대(`#lg-bar`)에 버튼 `data-panel="city"` "도시"를 추가(경제 모드에서만). 서랍 탭(`.lg-ptabs`)에도 `data-ptab="city"`.
- 서랍 내용(`#lg-city` 루트 안):
  1. 요약 줄: 주민(명, 지난달 대비 ±), 종사자(명, ±), 현금(억, 음수면 '지방채' 표시와 한도), 지지율(%, 다음 평가까지 남은 달과 통과 기준).
  2. 집단 6개 만족 막대(`.lg-grp`, 집단마다 `data-g="<집단 id>"`): 이름·비중·만족 0–100. 가장 낮은 집단에 "왜?" 한 줄(`.lg-why`).
  3. 정책(`#lg-econpol`): 주민 세율·산업 세율·공공서비스(−2..+2 단계, `input[type=range]` 또는 5단 버튼, 각각 `data-pol="taxRes|taxInd|service"`), 기업 유치 보조(억/달, `data-pol="incentive"`). 바꾸면 요청 `econ`을 보낸다(`send("econ", {taxRes, taxInd, service, incentive})`). 계획 단계에서만 바꿀 수 있고 그 밖에는 disabled. 각 조절기 옆에 "얻는 것 / 잃는 것" 한 줄(예: 세율↑ 세입↑ / 주민·기업 매력↓).
  4. 지난달 돈(`#lg-fiscal`): 세입 줄(재정지원금·주민세·산업세·전기요금 차익·전력 판매·사건 지원금) / 세출 줄(건설·연료·운영·공공서비스·유치 보조·이자) / 운영 수지(건설 제외). 엔진 보고서의 줄 이름을 그대로 쓰되 화면 이름은 한국어로.
  5. 이주 뉴스(`#lg-moves`): 지난달 우리 도시가 들고 난 흐름(어디서/어디로, 명, 이유).
  6. 기업 이전 희망(`#lg-offers`): 열린 제안마다 조건(MW·재생 %·정전·구직 인력) 대비 우리 상태를 ✓/✗로, 순위.
  7. 맨 아래 작은 글: "이주 속도 ×N(수업용 배속, 실제보다 빠름)" — N = `eduSpeed`.

## U2. 진행자 화면
- 순위표(`#lg-rank`, 경제 모드에서 `#lg-results` 위): 도시마다 총점과 부분 점수 6개(`pop ind fin co2 appr rel`, 화면 이름: 주민·산업·재정·탄소·지지·전력 신뢰), 순위 변화(지난달 대비 ▲▼). 부분 점수는 작은 막대.
- 이주 화살표: 광역 지도(`#lg-mapc` 캔버스) 위에 지난달 주민 흐름 상위 3개를 도시 사이 화살표로(굵기 = 명 수). 접근성: 같은 정보를 `#lg-mapcap` 글로도("A → B 1,200명: 정전이 잦아서").
- 국제 지수·뉴스 띠(`#lg-ticker`, 머리 막대 바로 아래): LNG·환율·수출·해운 지수(1 = 기준, ▲▼ 색), 진행 중인 국제 사건 이름, 이번 달 뉴스 앞 3개. 움직이는 띠라면 `prefers-reduced-motion`에서 멈춤.
- 팀 카드(`.lg-tcard`)에 주민 ±·지지율 한 줄 추가.

## U3. 혼자 하기(싱글플레이) — 컴퓨터 도시와 경쟁
- 목적: 교실 밖에서 학생 혼자 리그 경제 게임(달 턴)을 끝까지 할 수 있게. 멀티플레이와 **같은 규칙 엔진**(`KCP.leagueCore`·`KCP.econ`)을 쓰고, 네트워크 없이 한 탭에서 진행자 역할을 브라우저가 대신한다. 기존 #build 혼자 하기(샌드박스)는 그대로 둔다.
- 로비(`#league`)에 카드 "혼자 하기"(`#lg-solo`): 내 도시 고르기(활성 가능 도시, 평택 필수 규칙은 멀티와 같게 — 컴퓨터 도시 포함해 2~6곳), 게임 길이 12/24/36달, 컴퓨터 성향(신중·균형·공격, 기본 균형). 시작하면 `#league/solo`.
- 진행: 내 팀은 멀티 팀 화면과 같은 도시 지도·서랍(U1)을 쓴다. 컴퓨터 도시는 `ui/league-ai.js`(새 파일, 순수 함수 `KCP.leagueAI.plan(S, R, id, bg, style)` → 계획·정책·연계선 응답)를 따른다. 단계 넘기기는 내 '준비' 버튼(타이머 없음). 운영이 끝나면 결과·이주·순위가 내 화면에 보인다(U2 순위표·뉴스 띠를 팀 화면 서랍 '순위' 탭으로).
- 컴퓨터 도시 규칙(G): 1월마다 예산 안에서 자동 계획(정전 줄이기 우선, 성향에 따라 재생·디젤·연계선 비중과 세율 −1..+1), 연계선 제안은 비용 대비 자기 정전 감소가 있으면 수락. 결정적(씨앗 난수만), 한 달 계산 1초 이내.
- 저장: `localStorage` 키 하나(`kcp-league-solo-v1`)에 상태 전체. 새로고침해도 이어서. "처음부터" 버튼.
- 끝: 36(또는 12·24)달 뒤 최종 순위와 점수 부분, "무엇이 이 결과를 만들었나" 요약 세 줄(엔진 원인 문구에서), 활동지로 복사.
- 수용 기준: 혼자 하기 12달을 화면 클릭만으로 끝까지 진행(검사는 버튼을 눌러 진행), 컴퓨터 도시가 실제로 짓고(설비 수 > 0) 연계선에 답한다, 새로고침 후 이어짐, 콘솔 오류 0, 390×844 가로 스크롤 0. 멀티 화면과 계절 모드 동작은 바뀌지 않는다.

## U4. 면접 연결 장치와 결과 공개(근거: docs/ECON-INTERVIEW.md 3절·4절, docs/ECON-GAMES.md 11.1 S1–S4)
- '우리 기준' 카드(`#lg-crit`, INTERVIEW 3-1): 첫 달 계획 단계에 점수 6항목 중 1~2개 칩과 지킬 선 숫자 하나. 해가 바뀌면 유지/바꾸기(+이유 한 줄, 기기에만). D-59: 칩·숫자·유지/바꿈만 요청 `crit`으로 보내고 자유 서술은 보내지 않는다. 진행자 팀 카드에 칩 표시.
- '기준 먼저'·예측 칸(INTERVIEW 3-2, GAMES S2): 큰 결정(새 건설비 ≥ 예산 20%, 세율·서비스 변경, 연계선 제안) 달에만, 건너뛸 수 있음. 예측(정전·현금 방향)을 운영 뒤 결과 옆에 나란히(`.lg-pred`).
- 반문 카드(INTERVIEW 3-3, 질문 은행 4절): 결과 단계에 한 달 최대 한 장(`.lg-ask`), 조건에 맞는 질문 은행 항목, 고치겠다/유지하겠다 버튼 + 이유 한 줄(기기에만). 반대편끼리 짝지은 질문으로 한쪽으로 기울지 않게. 한 게임에 4~8회가 목표(문턱은 params가 아니라 league.js 상수로 두되 등급 G 주석).
- 분기 질문(3-4): 일지 탭 네 번째 칸. 끝 성찰(3-5): 끝 화면에 5문항 + "활동지로 복사"(기존 복사 확장).
- 결과 공개 순서(GAMES S2·S3): 운영 직후 팀 화면 결과 탭 맨 위에 '원인 막대'(지난달 주민·지지율 변화를 부분 점수 기여로 분해, 가장 큰 3개) — "왜?" 한 줄과 함께.
- 진행자 디브리핑(3-6, GAMES S4): 끝 단계 진행자 화면에 디브리핑 카드 5장(`#lg-debrief`, 공개 상태만으로), 그중 '점수 가중치 바꾸면 순위가 어떻게 바뀌나' 조절기(`#lg-wsim`, 계산은 `KCP.econ.score` 가중치를 바꿔 화면에서만).
- 순위표(U2)에 부분 점수별 1위 표시(GAMES S1). 팀 화면 순위 탭은 바로 위·아래 팀만 이름, 나머지는 순위 숫자만.
- 혼자 하기(U3, INTERVIEW 3-7): 같은 장치를 쓰되 팀 토의 문구 대신 혼자 쓰는 문구, 디브리핑 카드는 끝 화면에.

## v1.1 계약 보충(2026-10-04, 검사·구현 판정 결과)
- 서랍 탭은 단계가 바뀌면 자동으로 바뀐다(계획 단계 1월 → 일지, 결과·끝 → 결과). v1.2(2026-10-05, 영상 피드백 ⑥): 서랍 안 탭 줄(`.lg-ptabs [data-ptab]`)은 없애고 탐색은 아래 막대 `#lg-bar [data-panel=city|journal|result|rank|region|tech|deal]` 한 곳으로. 검사는 막대 버튼으로 연다.
- 순위표: 행 = `#lg-rank [data-team="<id>"]`(활성 팀 수만큼), 부분 점수 = 그 행 안 `[data-part="<키>"] meter[value]`(0–100), 총점 = `[data-total]`.
- `#lg-crit`는 일지 탭 안(1월 계획 단계에 일지 탭이 자동으로 열림).
- '기준 먼저·예측' 카드가 뜬 달에 '준비'를 누르면 카드가 열리고, 진행은 `#lg-ready-confirm`(이 기준으로 준비) 또는 `#lg-predict-skip`(건너뛰고 준비). 카드가 떠 있을 때 `#lg-ready`를 다시 누르면 건너뛰기와 같다.
- 컴퓨터 도시가 받은 연계선 제안을 거절하면 로그는 '제안 거절'(제안한 쪽이 거두면 '제안 거둠').

## U5. 팀 화면에서 지역 지도로 나가 다른 도시 관전(2026-10-05 사용자 요청)
- 평소 팀 화면은 우리 도시 지도만. 아래 막대에 버튼 `data-panel="region"` "지역 지도"(혼자 하기 포함). 누르면 **화면 전체**가 광역 지도 보기 `#lg-region`로 바뀐다(문명의 지도 축소처럼): 캔버스 `#lg-regionmap`(진행자 화면과 같은 렌더러 — 여섯 도시의 지금 계획 설비·송전선, 지난달 도시 사이 거래 선, 이주 화살표, 도시 이름·색), 도시마다 작은 요약 표지(설비 수·정전·지지율·주민 ±, 공개 상태에서), 위쪽에 `#lg-region-back` "우리 도시로".
- 광역 지도에서 다른 도시를 누르면 그 도시를 **관전**한다(`#lg-peek`): 그 도시 지도를 크게, 읽기 전용(건설·철거·정책·준비 조작 불가 — 막대의 준비·서랍 편집도 비활성), 위쪽에 "○○ 관전 중 · 읽기 전용", `#lg-peek-region` "지역 지도로", `#lg-peek-back` "우리 도시로". 우리 도시를 누르면 바로 우리 도시로.
- 우리 도시로 돌아오면 내 지도·편집 상태·서랍 그대로(관전 중 진행자 스냅이 와도 내 계획은 바뀌지 않음). 계획 단계 타이머·단계 전환 알림은 관전 중에도 보인다.
- 새로 보내는 정보 없음(계획은 이미 공개 상태 — D-59 범위 그대로). 계절 모드에서도 동작(지도 렌더러가 있는 지역). 390px에서 광역 지도는 화면 폭에 맞춰 축소·드래그 이동, 가로 스크롤 0, 조작 44px, 키보드로 도시 고르기(도시 버튼 목록).

## 수용 기준(검사가 확인할 것)
- 경제 모드 12달 진행 중 팀 화면: 도시 버튼·서랍·6집단 막대·정책 조절기 4개·지난달 돈 표·배속 문구가 보인다. 정책을 바꾸면 진행자 상태의 그 팀 `econPol`이 바뀐다. 계획 단계가 아니면 조절기가 disabled.
- 진행자 화면: 순위표에 활성 팀 수만큼 행, 부분 점수 6개, `#lg-ticker`에 지수 4개, 이주가 있는 달에 `#lg-mapcap`에 화살표 설명.
- 계절 4라운드 모드에서는 `[data-panel=city]`, `#lg-rank`, `#lg-ticker`가 없다(또는 hidden).
- U4: 경제 모드 첫 달 계획 단계에 `#lg-crit`가 보이고 칩을 고르면 진행자 상태의 그 팀 `crit`에 칩 키·숫자만 들어간다(자유 서술 없음). 결과 단계에 반문 카드는 많아야 하나. 끝 단계 진행자 화면에 `#lg-debrief`와 `#lg-wsim`.
- U5: 팀 화면 `[data-panel=region]` → 전체 화면 `#lg-region`·`#lg-regionmap`, 다른 도시 클릭 → `#lg-peek` 관전(건설·준비 비활성), `#lg-peek-back`으로 돌아오면 내 계획(설비 수)·서랍 그대로.
- 1280×900·390×844, 밝음·어두움에서 가로 스크롤 0, 콘솔 error·warning 0.
