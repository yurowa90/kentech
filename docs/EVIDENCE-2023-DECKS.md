# 2023 확장판 덱 근거 자료(직접 연 것만)

2023 확장판 덱 셋(물·인구·감염병)에 쓸 수 있는 외부 자료 목록이다. 2026-10-10에 갈래 세션이 직접 열어 내용을 확인한 것만 적는다. 목록에 없는 숫자는 덱에 넣지 않는다(D-66 원칙, D-70). 덱 자료 파일의 `evidence` 항목은 아래 번호를 쓴다.

등급: O = 공식 기관 원문을 직접 확인, O* = 공식 발표를 언론 보도나 요약으로 확인, P = 동료심사, M = 모형·추정, G = 게임 가정. O*는 덱에 넣을 때 '보도 기준'이라고 밝히고, 구현 전에 원문(보도자료·연보)을 열 수 있으면 O로 올린다.

낙인 방지(D-70): 실제 지역명이 나오는 수치(가뭄 단계 지역, 인구감소지역, 말라리아 발생 지역 등)는 출처·기준연도와 함께, 원인·구조를 설명하는 문장으로만 쓴다. 지역끼리 순위를 매기거나 '나쁜 곳'으로 읽히는 표현은 쓰지 않는다.
