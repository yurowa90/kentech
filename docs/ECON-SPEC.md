# 도시 경제 모형 SPEC v2 (ECON-BALANCE B1–B10) (경쟁형 에너지 타이쿤, 1턴 = 1달)

사용자 요구(2026-10-03):
- 재정: 해마다 국가 재정지원금 + 산업·주민 수에 따른 세금.
- 살기 좋고 편할수록 주민이 늘고, 산업 기반·자원 수급이 좋으면 산업이 발전한다.
- 지역 전체 주민·산업 총량은 정해져 있고 해마다 조금 는다. 주민과 기업은 더 좋은 도시로 옮긴다(기업은 이전 '희망'도 낸다).
- Democracy(정책 슬라이더·집단 지지·지연 효과), SimCity(RCI 수요), Civilization(산출·성장) 인사이트.
- 전체적으로 경쟁형 타이쿤. 해외 수입·수출·국제 물류·통상을 약간 반영. 1턴 = 1달.

원칙: 숫자마다 근거 등급 O/P/M/G(D-56). 실제 값(인구·종사자·재정 구조)은 O로 시작점에만 쓰고, 현실 이동률로 역산한 탄력은 M, 교육용 배속·반응 가중은 G로 둔다. 화면 글은 짧게.

## 1. 시간
- 1턴 = 1달. 게임 길이는 진행자가 고른다: 12 / 24 / 36턴(기본 12). 시작 2027년 1월.
- 1월마다 국가 재정지원금이 한 번에 들어온다. 그해 계획을 세우는 긴장.
- 전력 운영: 그 달 계절로 대표 7일을 돌려 비용·CO₂·정전을 달 일수/7배로 늘린다(정전 %는 그대로).
- 계절: 12·1·2 겨울, 3·4·5 봄, 6·7·8 여름, 9·10·11 가을.

## 2. 도시 상태(econ state, 도시마다)
- pop: 주민 수(명, 실제 규모). ind: 산업 규모(종사자 수, 명). 둘 다 실제 2024–2025 값에서 시작(O).
- cash: 에너지·산업 계정 잔액(억). 시작 = 지금 pack.budget. 음수가 되면 지방채(이자 월 0.3%, G). 한도 = 거래·사건 지원금·철거 회수를 제외한 최근 12달 세입의 50%. 12달 전에는 첫 달의 반복 세입 × 12 + 연 지원금으로 추정한다.
- taxRes, taxInd: 세율 단계 -2..+2(기본 0). 높을수록 세입↑, 매력↓.
- service: 공공서비스 지출 단계 -2..+2(기본 0). 주민 1인당 비용, 생활 만족↑.
- incentive: 기업 유치 보조(억/달), 산업 매력↑.
- 집단 지지(Democracy): 집단 6개 — 직장인, 청년, 노년, 기업, 농어민, 환경단체. 집단마다 비중(인구 비율, 도시마다 다름)과 만족 0–100.
- 지연 효과: 정책·투자의 효과는 목표값으로 바로 가지 않고 달마다 λ(0.5, G)만큼 다가간다.

## 3. 매력도
### 3.1 살기 좋음 L(0–100)
가중 평균(가중치 G, 데이터 파일에서 조정):
- 전력 신뢰: 정전% 0 → 100, ≥16% → 0(5% 정전과 전면 정전을 구분). 병원 정전이 있으면 −20.
- 전기요금 부담: 도시 전력 원가(억/MWh, (연료+정책 비용)/수요)를 지역 평균과 비교한다. 거래 수지는 제외한다. 평균에는 0원 도시도 포함하고, 원가 누락은 기준 원가 0.012로 채운다. 점수 계산에만 평균 × 0.5의 하한을 적용한다(부분 점수 최대 75).
- 대기질: 지역 배출(석탄·디젤·LNG·바이오매스 CO₂를 대기오염 대리 지표로, t/주민 만 명).
- 일자리: ind/pop을 지역 평균과 비교.
- 공공서비스: service 단계 + 대학·연구소(교육) 보너스.
- 세금 부담: taxRes.
- 혼잡: pop / 주거 수용(도시 타일 수 × 기준). 넘치면 감점(SimCity 'R 수요' 포화).
### 3.2 산업 매력 A(0–100)
- 전력 신뢰(가중 큼, 반도체·데이터센터가 민감), 전력 단가, 재생 비중(RE100 요구 업종 비중만큼), 인력(pop 규모·청년 비중), 대학·연구소(인재), 물류(항만·국가산단 site가 있으면 + , 국제 물류 지수에 연동), 세금(taxInd), 보조(incentive), 산업 용지(산단 site 수용 대비 ind).

## 4. 이동(이주·기업 이전)
- 지역 총량: POP_TOT(y) = 합계 × (1+gp)^y, IND_TOT(y) = 합계 × (1+gi)^y(gp, gi는 데이터에서, 월 단위로 나눠 적용).
- 실효 매력: 주민 `Leff = L − anchor × 시작 L`, `anchor=0.9`(G). 산업 `Aeff = A − 시작 A`는 시작 대비 개선량만 비교한다. 대학·인구 규모의 시작 우위를 유치 순위에 남기지 않는다. 각 값은 현재 가중치로 지연 부분 점수와 시작 부분 점수를 합산해 계산한다.
- 목표 몫: `s_i* = w_i · exp(β·(실효 매력_i − 지역 평균)/10) / Σ_j(...)`, `w_i = (1 − startMix) × 현재 몫 + startMix × 시작 몫`.
- 현실 탄력 `betaPopReal=0.08`, `betaIndReal=0.08`(M; 산업은 주민 값 준용)에 교육용 `eduSpeed=1.25`(G)를 곱한다. 실효 β는 각각 0.10이다. 공개 상태 `publicView(S).econ.eduSpeed`로 배속을 전달한다. **배속은 탄력의 배수**이며 전체 이주율의 현실 배수는 아니다.
- 달마다 `pop_i += κ_pop × (s_i* × POP_TOT − pop_i)` + 자연 증가 몫. `κ_pop=0.04`, `κ_ind=0.005`, `startMix=0.9`(모두 G). B1의 제안 기본값 0.2는 정전 해소 후 회복 목표를 만족하지 못해 0.9로 조정했다. 지연 반영률은 0.5다.
- 산업도 같은 꼴. 3–6턴마다 기업 이전 희망(종사자 N명, 여유 전력 M MW, 재생 요구 r%)이 생긴다. 조건을 충족한 도시 중 **Aeff 순위**로 정하며, 동점은 씨앗 난수로 결정한다.
- `spareMW`가 없으면 전력 조건 불충족. 리그는 대표 주 최대 수요 시각의 `gx.ren + gx.head − 미공급 수요`를 0 이상으로 제한해 넘긴다. 계통 접속 발전망의 잉여 재생·추가 화력 출력으로 계산하며, 고립망·추가 수입·배터리의 미사용 방전 능력은 포함하지 않는 보수적 추정이다.
- 이동은 보존: 한 도시가 잃은 만큼 다른 도시가 얻는다(총량 = POP_TOT). 반올림 오차 없이.
- 뉴스는 가장 큰 흐름이 `max(newsMin=100명, 출발 도시의 이동 전 규모 × newsFrac=0.0005)` 이상일 때만 낸다. 주민은 pop, 산업은 ind 기준이며 이름은 도시 자료에서 읽는다.

## 5. 재정(달마다)
- 세입:
  - 1월 국가 재정지원금: 기본 + 1인당 + 재정자립도 균형분 + **도시별 정액 보정 지원금**. 마지막 항은 시작 보통 조건의 연 운영 수지가 `fiscalTarget=0.6 × cash0`가 되도록 init/calibrate 때 한 번 계산한다. 세율 단가에 도시별 배수를 곱하지 않는다. `rev.subsidy`에 합산하고 `fiscal.equalize`·1월 뉴스에 세부 금액을 표시한다.
  - 주민 관련 세: `pop × resTax(0.00003억/명·달) × (1 + taxStep(0.1) × taxRes)`.
  - 산업 관련 세: `ind × indTax(0.000018억/명·달) × 산출 지수 × (1 + taxStep × taxInd)`. 산출 지수는 정전·수출·물류에 따라 0.5–1.2.
  - 전기 **차익**: `rev.tariff = demMWh × (지역 평균 원가 × (1 + tariffMarkup=0.02) − 자기 원가)`. 음수 가능. 총 매출은 참고값 `fiscal.tariffGross`로만 보고한다.
  - 거래 벌이 `rev.trade`, 사건 지원금 `rev.bonus`, 철거 회수 `rev.salvage`. 일회성 지원금은 `fiscal.eventBonus`에도 표시하며 B6 비교 시 뺀다.
- 세출: 새 건설 `capex`, 차익에서 이미 차감한 전력 원가를 제외한 운영비 `opex`(대응·연구 등), 서비스 `pop × svcCost(0.00006) × (1 + svcStep(0.5) × service)`, 기업 보조, 지방채 이자(월 0.003), 거래 지출, 시위 중 정책 변경 비용. 전력 원가를 차익과 지출에서 두 번 빼지 않는다.
- 연 운영 수지 = 12달 `revTotal − expTotal + exp.capex`의 합. 보통 조건에서 시작 현금의 0.4–0.8배가 목표다. 실측 세율·서비스 조합과 계수 근거는 ECON-DATA 9절.
- 지방채: `debtCap = debtCapRatio(0.5) × 최근 12달 세입`. 거래·사건 보너스·철거 회수는 한도 산정에서 제외한다. 12달이 안 쌓였으면 첫 달 반복 세입의 연 환산 + 연 지원금을 유지한다(1월 지원금을 12배하지 않음).
- 경제 모드 건설 예산: `cash + debtCap + committed + tieAt − tieShare + 아직 안 받은 사건 지원금`. 현금이 `−debtCap`보다 작으면 계획 검사와 연계선 수락에서 새 건설을 거부한다. 기존 설비 운영·철거·정책 변경은 가능하다.
- 현금 항등식: `cashBefore + revTotal − expTotal = cashAfter`. 사건 보너스와 철거 회수도 econ 입력으로 전달하고, monthStep 뒤 현금을 별도로 바꾸지 않는다. `yearStart`는 1월·paidYear 가드로 중복 지급을 막는다.

## 6. 전력 수요와의 연결(핵심 순환 고리)
- 마을(주거·상업) 수요 × pop_i / pop0_i, 산업 site(factory_big, industry, port) 수요 × ind_i / ind0_i.
- 그래서 주민·기업이 늘면 전기가 더 필요 → 투자 → 정전이 줄면 더 몰려옴. 반대로 정전·비싼 전기 → 떠남 → 세입 감소.
- build.js에는 MODS.demandRes, MODS.demandInd 배수 손잡이를 더한다(리드가 함).

## 7. 국제(약간)
- 전역 지수(달마다, 씨앗 고정): LNG 수입 가격 지수(LNG·디젤 연료비 배수), 환율, 수출 수요 지수(반도체·자동차·철강), 해운 물류 지수(항만 도시 산출에 영향).
- 사건: 해운 차질(홍해 등), LNG 가격 급등, 수출 호황, CBAM(EU 탄소국경조정 — 철강 수출 도시는 전력 탄소집약도만큼 산업 산출 감점), 공급망 기자재 가격 상승(설계안 E01–E04).
- 수출 비중이 큰 도시(산업 구성)는 수출 지수에 더 민감.

## 8. Democracy 인사이트
- 정책 = 슬라이더(세율, 공공서비스, 보조, 기존 정책 카드). 정책 하나가 여러 집단·지표에 서로 다른 크기·부호로, 시차를 두고 영향.
- 집단 만족 → 지지율(집단 비중 가중). 12턴마다 '평가'(선거 대신 주민 평가): `approval < approval0 − approvalDrop(10)`이면 다음 해 정책 바꾸기 비용↑·시위 사건.
- `approval0`는 calibrate 뒤 초기 집단 만족으로 계산해 도시 상태에 고정한다. 세금·서비스 단계당 부분 점수 20점, 집단별 정전 가중 0.20–0.35(G)로 정책 결과를 반영한다.
- 화면: 집단 6개 막대 + "왜?" 한 줄(가장 큰 원인).

## 9. 점수(경쟁형 타이쿤)
- 점수 부분 키는 정확히 `pop, ind, fin, co2, appr, rel`. 가중치는 각각 0.20, 0.20, 0.10, 0.15, 0.15, 0.20(G). 주민·산업은 지역 성장률을 뺀 몫 증가율이다.
- 재정 건전성 `fin`: 현금 ≥ 0이면 100, 부채가 있으면 `clamp(100 × (1 + cash/debtCap), 0, 100)`. 한도가 0이고 빚이 있으면 0. 현금 비축 자체에는 가산하지 않는다. 지역 공동 목표(D-54)는 별도다.
- 순위표: 진행자 화면.

## 10. 모듈 경계
- ui/econ-data.js: KCP.ECON_DATA = { start: {도시별 pop0, ind0, 집단 비중, 항만 여부, 수출 비중, 산업 구성}, params: {가중치·계수, 각 등급·출처}, intl: {지수 기본값·사건}, sources }.
- ui/econ.js: KCP.econ = 순수 함수(화면 없음, DOM 없음, Math.random 금지 — 씨앗 난수만):
  - initCities(ids, data) → econ 상태 {month, year, cities:{id:{pop, ind, cash, tax..., groups, lag...}}, intl, totals}
  - livability(city, ctx) / industryAttract(city, ctx) → {score, parts:{...}}(설명용 부분 점수)
  - monthStep(E, inputs, data) → {E', report}: inputs = 도시마다 {energy:{unsPct, hospH, costPerMWh, co2Local, renPct, tradeNet, opex, capexNew, bonus, salvage, spareMW}, policy:{taxRes, taxInd, service, incentive}, assets:{uni, lab, port, ...}}; report = {flows: 이주·이전 표, revenue/expense 내역, groups, news[]}
  - yearStart(E, data) → 재정지원금 지급
  - demandMul(city, city0) → {res, ind}
  - score(E) → 순위
- 불변 조건(테스트): 주민·산업 총량 보존(이동은 합 0, 총량 = 성장식), 같은 입력·씨앗 → 같은 결과, cash 회계 항등식(전 + 세입 − 세출 = 후), 모든 점수 0–100, NaN 없음, 극단 입력(정전 100%, 세율 ±2)에서도 범위 유지, 36턴 돌려도 한 도시가 전부 가져가지 않음(관성).

## 11. 달 턴·보고서 계약
- `monthStep`은 `E.t >= E.len`이면 원 상태와 `report:null`을 돌려준다.
- `report.fiscal[id]`: `rev`, `exp`(capex 포함), `revTotal`, `expTotal`, `cashBefore`, `cashAfter`, `debtCap`, `debtOver`, `tariffGross`, `eventBonus`. `equalize`는 subsidy에 이미 포함된 세부 금액이다.
- `report.groups[id].approval`, 평가 달의 `report.review[id].pass`, `report.cities[id]`의 `pop/ind/Leff/Aeff/Lparts/Aparts`를 제공한다.
- 리그 달 턴 사건은 확률 0.5로 0/1개. 바로 전 달에 나온 사건은 제외한다. 계절 4라운드의 1/2개 추첨은 유지한다.
- 미사용 `fk/fiscalNorm`, `L0/A0`, `capexMul`과 효과가 없던 기자재 사건은 제거했다. 부분 점수 계수는 econ-data의 등급 있는 params에서 읽는다.
