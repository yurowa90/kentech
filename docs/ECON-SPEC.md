# 도시 경제 모형 SPEC v1 (경쟁형 에너지 타이쿤, 1턴 = 1달)

사용자 요구(2026-10-03):
- 재정: 해마다 국가 재정지원금 + 산업·주민 수에 따른 세금.
- 살기 좋고 편할수록 주민이 늘고, 산업 기반·자원 수급이 좋으면 산업이 발전한다.
- 지역 전체 주민·산업 총량은 정해져 있고 해마다 조금 는다. 주민과 기업은 더 좋은 도시로 옮긴다(기업은 이전 '희망'도 낸다).
- Democracy(정책 슬라이더·집단 지지·지연 효과), SimCity(RCI 수요), Civilization(산출·성장) 인사이트.
- 전체적으로 경쟁형 타이쿤. 해외 수입·수출·국제 물류·통상을 약간 반영. 1턴 = 1달.

원칙: 숫자마다 근거 등급 O/P/M/G(D-56). 실제 값(인구·종사자·재정 구조)은 O로 시작점에만 쓰고, 반응 계수(이주 탄력 등)는 G로 둔다. 화면 글은 짧게.

## 1. 시간
- 1턴 = 1달. 게임 길이는 진행자가 고른다: 12 / 24 / 36턴(기본 12). 시작 2027년 1월.
- 1월마다 국가 재정지원금이 한 번에 들어온다. 그해 계획을 세우는 긴장.
- 전력 운영: 그 달 계절로 대표 7일을 돌려 비용·CO₂·정전을 달 일수/7배로 늘린다(정전 %는 그대로).
- 계절: 12·1·2 겨울, 3·4·5 봄, 6·7·8 여름, 9·10·11 가을.

## 2. 도시 상태(econ state, 도시마다)
- pop: 주민 수(명, 실제 규모). ind: 산업 규모(종사자 수, 명). 둘 다 실제 2024–2025 값에서 시작(O).
- cash: 에너지·산업 계정 잔액(억). 시작 = 지금 pack.budget. 음수가 되면 지방채(이자 월 0.3%, G). 한도 = 연간 세입의 50%.
- taxRes, taxInd: 세율 단계 -2..+2(기본 0). 높을수록 세입↑, 매력↓.
- service: 공공서비스 지출 단계 -2..+2(기본 0). 주민 1인당 비용, 생활 만족↑.
- incentive: 기업 유치 보조(억/달), 산업 매력↑.
- 집단 지지(Democracy): 집단 6개 — 직장인, 청년, 노년, 기업, 농어민, 환경단체. 집단마다 비중(인구 비율, 도시마다 다름)과 만족 0–100.
- 지연 효과: 정책·투자의 효과는 목표값으로 바로 가지 않고 달마다 λ(0.25, G)만큼 다가간다.

## 3. 매력도
### 3.1 살기 좋음 L(0–100)
가중 평균(가중치 G, 데이터 파일에서 조정):
- 전력 신뢰: 정전% 0 → 100, ≥5% → 0. 병원 정전이 있으면 −20.
- 전기요금 부담: 도시 평균 전력 비용(억/MWh, 연료+거래 수지/수요)을 지역 평균과 비교.
- 대기질: 지역 배출(석탄·디젤·LNG·바이오매스 CO₂를 대기오염 대리 지표로, t/주민 만 명).
- 일자리: ind/pop을 지역 평균과 비교.
- 공공서비스: service 단계 + 대학·연구소(교육) 보너스.
- 세금 부담: taxRes.
- 혼잡: pop / 주거 수용(도시 타일 수 × 기준). 넘치면 감점(SimCity 'R 수요' 포화).
### 3.2 산업 매력 A(0–100)
- 전력 신뢰(가중 큼, 반도체·데이터센터가 민감), 전력 단가, 재생 비중(RE100 요구 업종 비중만큼), 인력(pop 규모·청년 비중), 대학·연구소(인재), 물류(항만·국가산단 site가 있으면 + , 국제 물류 지수에 연동), 세금(taxInd), 보조(incentive), 산업 용지(산단 site 수용 대비 ind).

## 4. 이동(이주·기업 이전)
- 지역 총량: POP_TOT(y) = 합계 × (1+gp)^y, IND_TOT(y) = 합계 × (1+gi)^y(gp, gi는 데이터에서, 월 단위로 나눠 적용).
- 목표 몫: s_i* = w_i · exp(β·(L_i − L̄)/10) / Σ_j(...), w_i = 현재 몫(관성). β_pop G.
- 달마다 pop_i += κ_pop · (s_i*·POP_TOT − pop_i)(κ_pop ≈ 0.01, G) + 자연 증가 몫(총량 증가분을 현재 몫대로).
- 산업도 같은 꼴(β_ind, κ_ind ≈ 0.005, G). 또 3–6턴마다 '기업 이전 희망' 사건: 큰 기업 하나(종사자 N명, 필요 전력 M MW, 재생 요구 r%)가 조건을 내건다 → 도시들이 조건을 맞추거나 보조를 제안 → 진행자가 조건 충족 + 매력 순으로 정한다(공개 유치 제안, 설계안 §10).
- 이동은 보존: 한 도시가 잃은 만큼 다른 도시가 얻는다(총량 = POP_TOT). 반올림 오차 없이.
- 뉴스 한 줄: "평택 → 천안 1,240명 이주: 정전이 잦아서"(가장 큰 흐름과 가장 큰 원인 요소).

## 5. 재정(달마다)
- 세입:
  - 국가 재정지원금(1월 한 번): 기본 + 1인당 + 균형(재정자립도가 낮을수록 더, 지방교부세 원리, M/O). 규모는 G로 맞추되 비율 구조는 실제 재정 구조를 참고.
  - 주민 관련 세(달마다): pop × 단가 × (1 + 0.1·taxRes).
  - 산업 관련 세(달마다): ind × 단가 × 산출 지수 × (1 + 0.1·taxInd). 산출 지수 = 정전·수출 수요·물류에 따라 0.5–1.2.
  - 전력 거래 수지(리그 정산 결과).
- 세출: 새 건설(capex), 연료·정책·대응·연구소 운영비(월 환산), 공공서비스(pop × 단가 × (1+0.25·service)), 보조(incentive), 지방채 이자.
- 현금이 모자라면 건설 불가(지금 '예산' 자리를 cash가 대신). 기존 철거 회수·현금 흐름 규칙(D-56)은 그대로.

## 6. 전력 수요와의 연결(핵심 순환 고리)
- 마을(주거·상업) 수요 × pop_i / pop0_i, 산업 site(factory_big, industry, port) 수요 × ind_i / ind0_i.
- 그래서 주민·기업이 늘면 전기가 더 필요 → 투자 → 정전이 줄면 더 몰려옴. 반대로 정전·비싼 전기 → 떠남 → 세입 감소.
- build.js에는 MODS.demandRes, MODS.demandInd 배수 손잡이를 더한다(리드가 함).

## 7. 국제(약간)
- 전역 지수(달마다, 씨앗 고정): LNG 수입 가격 지수(LNG·디젤 연료비 배수), 환율, 수출 수요 지수(반도체·자동차·철강), 해운 물류 지수(항만 도시 산출에 영향).
- 사건: 해운 차질(홍해 등), LNG 가격 급등, 수출 호황, CBAM(EU 탄소국경조정 — 철강 수출 도시는 전력 탄소집약도만큼 산업 산출 감점), 공급망 기자재 가격 상승(설계안 E01–E04).
- 수출 비중이 큰 도시(산업 구성)는 수출 지수에 더 민감.

## 8. Democracy 인사이트
- 정책 = 슬라이더(세율, 공공서비스, 보조, 기존 정책 카드). 정책 하나가 여러 집단·지표에 서로 다른 크기·부호로, 시차를 두고 영향.
- 집단 만족 → 지지율(집단 비중 가중). 12턴마다 '평가'(선거 대신 주민 평가): 지지율 < 35%면 다음 해 정책 바꾸기 비용↑·시위 사건.
- 화면: 집단 6개 막대 + "왜?" 한 줄(가장 큰 원인).

## 9. 점수(경쟁형 타이쿤)
- 도시 점수 = 주민 증가율, 산업 증가율, 현금(부채 감점), 1인당 CO₂, 지지율, 정전 — 각 0–100으로 바꿔 가중 합. 지역 공동 목표(D-54)는 따로.
- 순위표: 진행자 화면.

## 10. 모듈 경계
- ui/econ-data.js: KCP.ECON_DATA = { start: {도시별 pop0, ind0, 집단 비중, 항만 여부, 수출 비중, 산업 구성}, params: {가중치·계수, 각 등급·출처}, intl: {지수 기본값·사건}, sources }.
- ui/econ.js: KCP.econ = 순수 함수(화면 없음, DOM 없음, Math.random 금지 — 씨앗 난수만):
  - initCities(ids, data) → econ 상태 {month, year, cities:{id:{pop, ind, cash, tax..., groups, lag...}}, intl, totals}
  - livability(city, ctx) / industryAttract(city, ctx) → {score, parts:{...}}(설명용 부분 점수)
  - monthStep(E, inputs, data) → {E', report}: inputs = 도시마다 {energy:{unsPct, hospH, costPerMWh, co2Local, renPct, tradeNet, opex, capexNew}, policy:{taxRes, taxInd, service, incentive}, assets:{uni, lab, port, ...}}; report = {flows: 이주·이전 표, revenue/expense 내역, groups, news[]}
  - yearStart(E, data) → 재정지원금 지급
  - demandMul(city, city0) → {res, ind}
  - score(E) → 순위
- 불변 조건(테스트): 주민·산업 총량 보존(이동은 합 0, 총량 = 성장식), 같은 입력·씨앗 → 같은 결과, cash 회계 항등식(전 + 세입 − 세출 = 후), 모든 점수 0–100, NaN 없음, 극단 입력(정전 100%, 세율 ±2)에서도 범위 유지, 36턴 돌려도 한 도시가 전부 가져가지 않음(관성).
