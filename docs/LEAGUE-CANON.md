# 전력 리그 확정 규칙 (1쪽)

2026-10-07 초안. 이 쪽은 지금 확정된 것만 적는다. 근거와 자세한 계약은 결정 기록(DECISIONS.md)과 명세(ECON-*)에 있다. **확정**은 결정 번호가 있는 것, **제안**은 발전안·게임 비교에서 나왔지만 아직 시안을 비교하지 않은 것, **미정**은 선생님이 정할 것이다. 새 기능은 아래 '핵심 60초'의 어느 장면을 강하게 하는지 말할 수 없으면 넣지 않는다.

## 핵심 재미
내 도시의 전기와 살림을 맡아, 화면에 있는 근거 하나로 다음 달을 예측하고, 결과가 왜 그렇게 나왔는지 원인을 찾아 고친다. 이웃 도시와는 경쟁하면서도 연계선·거래로 기대야 하고, 그 부담을 누가 지느냐가 갈등이 된다.

## 학습 목표 (초안 — 선생님 문장으로 고칠 자리)
1. 데이터를 보고 선택한다(수요·예보·접속 여유·연료 가격).
2. 같은 설비도 놓는 자리에 따라 손실·민원·접속 대기가 달라짐을 안다.
3. 한 가지 정답 전략이 없고, 전략마다 대가가 있음을 안다.
4. 예측 → 실제 비교 → 유지·수정의 순서로 생각한다(켄텍 면접의 사고 습관).
5. 발전소·송전선의 편익과 부담이 다른 사람에게 돌아가는 사회적 쟁점을 말할 수 있다.
6. 실패의 원인을 날씨·이웃·접속·내 선택으로 나눠 설명한다.
7. 실제 자료와 게임 가정(G)을 구분한다.

## 핵심 60초 (한 달 한 바퀴)
S1 이번 달 근거 하나 확인 → S2 설비 하나를 어디에 둘지 판단(민원·전력망 렌즈) → S3 1주 시험 운전 → S4 약속(근거·방향·확신) → S5 준비·운영 → S6 예측 대 실제 → S7 원인 하나 → S8 다음 달에 바꿀 것. 영상·검토·피드백은 이 장면 번호로 말한다.

## 확정 (바꾸려면 새 결정 번호)
- 1턴 = 1달, 12·24·36달(D-57). 외부 스크립트 금지(D-31).
- 도시 이름은 자료에서만 읽고, 첫 교실 시범 수업 전에 가상 이름으로 바꾼다(D-58, D-65).
- 학생 입력은 기기 밖으로 보내지 않는다. 예외는 기준 칩·숫자(D-59)와, 앞으로 만들 송전 회랑 응답 하나뿐이다(D-65). 하루 전 약속·확신·관찰 메모는 기기 안에만.
- 화면에는 실제 자료 값만 출처·기준연도·단위와 함께, 나머지는 '게임 가정(G)' 한 줄(D-60). 출처 줄의 공공기관·언론명만 허용(D-63).
- 지역 공동목표 보너스와 도시별 기여 표시(D-61). 민원·이익공유·절전은 집단 만족에 연결(D-62).
- 팀·진행자 메시지 서명, 방 코드 8자리, 판마다 다른 날씨·사건(고정 선택 가능), 공개 상태 20만 바이트 상한(D-64).
- 면접 무대 기본은 결정 카드 + 짝 청문. 시민참여단 청문회는 24·36달·3차시 선택지(D-65).
- 모형의 수식·계수는 공인 출처를 열어 확인한 것만 근거로 쓴다. 밸런스는 게임 가정(G) 손잡이로만 맞추고, 근거 값과 단위의 의미를 비틀지 않는다. 시간 압축은 모든 흐름에 같게 적용한다(이동·SMR 공사 ×4.4). 필수 밸런스 기준은 '한 전략이 여섯 도시를 독식하지 않는다'(B16) 하나다(D-66 예정).

## 이번 범위 (2026-10-07)
재보정 통합(근거 대장 기반 계수·식), 전체 검사(node·브라우저·실제 Supabase·회귀 14종), 혼자 하기·6팀 영상을 장면 번호로 찍고 장면별 재확인, 화면 기능을 핵심·보조·보류로 분류.

## 제안 (시안 비교 뒤에 정함)
발전안의 4막 구조·위기의 밤 재생·연출 대본·송전 회랑과 정의 장부·면접 무대, 게임 비교의 '다음' 목록. 큰 기능은 움직이는 시안 2~3개를 먼저 보이고 고른 뒤 구현한다. 첫 대상은 송전 회랑.

## 미정 (선생님 결정)
학습 목표 문장, 기능 분류 결과, 송전 회랑 시안 선택, 이미 올린 커밋의 모델 이름 줄 처리, 다른 해 기출 재정비 시작 시점.
