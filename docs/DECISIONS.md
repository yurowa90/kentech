- 대안: OpenAI API 직접 호출 / 사용자의 Mac Codex CLI 원격 제어 / Claude 하위 에이전트.

### D-02 PR 단계를 나누고 앞 PR 위에 쌓는다 (2026-10-02, 유효)
- 맥락: 기출 재현, 창작 게임 검토, 화면 시안을 사용자가 따로 검토하길 원함("UI 시안은 별도 변경으로").
- 결정: #1 기출 충실도, #2 창작 게임 검토, 화면 시안은 #2 브랜치 위에 쌓은 초안 PR.
- 결과: #2가 바뀌면 시안 브랜치에 병합(merge)으로 가져온다. 역사 재작성 금지.

### D-03 PR 감시 주기 알림을 걸지 않는다 (2026-10-02, 유효)
- 근거: 사용자가 확인 알림을 원치 않음("그만").
- 결과: PR 이벤트 구독만 하고 send_later 주기 점검은 하지 않는다.

### D-04 기준선은 같은 검사를 기준 브랜치에서 돌려 정한다 (2026-10-02, 유효)
- 맥락: 샌드박스에서 구글 폰트 TLS 실패가 콘솔 오류로 잡혀 '문제 0'이 불가능.
- 결정: 폰트 인증서 오류를 뺀 '실제 문제'가 0이고 문제 수가 기준선과 같으면 통과로 본다.
- 결과: 기준선 표는 스킬 `kcp-run-tests`. 같은 원인으로 늘 실패하는 단언(screens T0b-2, s-riverdeal 12.4-5, s-shuttle-permit SP-12.4-08)은 무시. PR #1 본문의 '단언 실패 0건' 과장을 이 근거로 고쳤다.

### D-05 Python Playwright 1.56.0 고정 (2026-10-02, 유효)
- 근거: 1.63은 설치되지 않은 chromium_headless_shell-1243을 찾는다. 설치된 chromium-1194와 맞는 버전이 1.56.0.

## 화면 시안 v2

### D-30 대표 게임은 섬 전력망 24시 (2026-10-02, 유효)
- 대안: 공간·지도가 있는 게임 가운데 선택. 은여울강(지도), 섬(헥스 섬).
- 근거: 참고 화면(로우폴리 헥스 섬, 남색 UI)과 가장 가깝고, 사용자의 "문명 게임 같은" 요청에 헥스 지도가 맞는다. 시간축(8구간)이 '다음 턴'으로 자연스럽게 옮겨진다.

### D-31 3D는 WebGL·외부 라이브러리 없이 Canvas 2D 자체 엔진 (2026-10-02, 유효)
- 대안: three.js(CDN) / WebGL 직접 / CSS 3D / Canvas 2D.
- 근거: 외부 요청과 WebGL 콘솔 경고가 검사 '문제'로 잡히고, 정적 앱에 의존성을 늘리지 않기 위해. 로우폴리 양식은 면 단위 평면 음영이면 충분하다.
- 결과: 원근 카메라 + 칸 묶음 단위 화가 알고리즘 + 람베르트 평면 음영, 고르기는 화면 다각형 판정. 고칠 때 `games/s-island-grid-scene.js`의 '그리기' 절.

### D-32 섬 장면은 게임 계산을 읽기만 하고, 사용자가 장면에서 누른 조작만 게임 함수로 보낸다 (2026-10-02, 유효)
- 근거: 모형·저장·판정을 바꾸지 말라는 요구. 게임과의 결합을 최소화.
- 결과: 계약은 `ig:prep {root, api}`, `ig:paint` 두 이벤트뿐. 장면이 자동으로 계획을 바꾸는 일은 없다. 시간 막대는 '보는 구간'만 바꾼다.

### D-33 시험 전에는 S1 미리보기만, S2·S3와 급전선별 차단은 시험 뒤 공개 (2026-10-02, 유효)
- 근거: 게임은 첫 예측을 첫 시험 때 잠근다. 장면이 시험 전에 다른 날씨 결과를 보여 주면 예측 과제가 무너진다.

### D-34 섬만 '장면 전체 화면 + 고정 패널', 나머지 네 게임은 문서 흐름 + 위쪽 장면 (2026-10-02, 유효)
- 맥락: 사용자가 다른 게임에도 고전 게임 오마주를 요청.
- 근거: 시멘트 검사가 창 스크롤과 `#strip` 바로 아래 sticky 요약 띠(`#cc-mini`, top = 띠 높이)를 요구한다. 셔틀·은여울강 검사도 문서 폭과 버튼 높이를 직접 잰다. 전체 화면 패널로 옮기면 이 계약이 깨진다.
- 결과: 문서형 게임은 `#strip`의 top을 0으로 두고 색·글꼴·테두리만 바꾼다. 장면 전체 화면형으로 넓히려면 그 게임 검사의 배치 단언부터 다시 설계해야 한다.

### D-35 첫 화면에 자동으로 안내 창을 띄우지 않는다 (2026-10-02, 유효)
- 근거: 빈 저장소로 시작하는 검사에서 모달이 클릭을 막는다. 안내는 단계 카드·'브리핑' 버튼으로 연다.

### D-36 섬 첫 화면은 12–15시(한낮) (2026-10-02, 유효)
- 근거: 기본 선택 칸 00–03시는 밤이라 첫인상이 어둡다. 계획 칸을 고르면 그 구간을 따라간다.

### D-37 휴대폰과 세로 태블릿(≤1100px 세로)은 아래 메뉴 + 아래 시트 (2026-10-02, 유효)
- 근거: 768×1024에서 오른쪽 패널(440px)이 섬을 가렸다. 시트 높이 34vh는 검사(그래프 가운데 맞춤 뒤 좌표 탭)가 통과하는 최소 높이에 여유를 둔 값.
