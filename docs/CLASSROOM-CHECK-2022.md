# 2022 충실판 교실 시범 전 확인

2022 미션 켄텍 연습(`#y2022`)을 수업에 처음 쓰기 전에 사람이 직접 확인할 세 가지다. 개발 완성 판정(AUDIT-2022 §9)의 차단 조건은 아니다. 자동 검사가 볼 수 없는 것만 남겼다. 학생 이름·학번 등 개인정보는 기록하지 않는다. 기록은 통과·미통과와 관찰 메모(누가 했는지 없이)만 남긴다.

| | 화면 낭독기 | 실제 태블릿 | 가정 카드 오해 여부 |
|---|---|---|---|
| 누가 | 교사 1명 | 교사 1명(가능하면 학생 1명이 조작) | 교사, 시범 수업 학생 3~6명 |
| 기기 | Mac Safari + VoiceOver(⌘F5), 또는 iPad VoiceOver | 수업에 쓸 태블릿 1대(가로·세로 모두) | 수업 기기 그대로 |
| 시간 | 약 15분 | 약 10분 | 성찰 단계 안에서 약 10분 |

## 1. 화면 낭독기
1. 준비실에서 Tab으로 지도에 들어간다. 칸 하나에서 "좌표, (발전소), 지형, 데이터"가 읽힌다.
2. 방향키(↓ 한 번)로 B1에 가서 풍력 도구로 Enter를 누른다. "B1에 풍력 발전소를 설치했습니다. 생산 20." 같은 알림이 한 번 읽힌다.
3. 바다 칸에 원자력을 놓아 본다. 오류 문장이 한 번만 읽힌다(두 번 읽히면 미통과).
4. 2번 문제 탭에서 전선 도구로 A1→A4를 키보드만으로 놓고, Esc로 시작점 취소가 읽히는지 본다.
5. 성찰의 '조건이 바뀐다면'에서 카드를 바꿔 누를 때마다 결과 숫자가 읽힌다.
- **통과:** 1~5를 화면을 보지 않고 끝낼 수 있고, 같은 알림이 겹쳐 읽히지 않는다.

## 2. 실제 태블릿
1. 세로 방향 준비실에서 지도를 옆으로 밀어 J10까지 볼 수 있고, 페이지 전체는 옆으로 밀리지 않는다.
2. 손가락으로 칸 10개를 연달아 눌러 의도한 칸에만 놓인다(옆 칸 오조작 0~1회까지 통과).
3. 전선 도구로 시작점·끝점을 눌러 전선을 놓고 지운다.
4. 면접실에서 첫 질문 카드가 화면 위쪽에 먼저 보이고, 장면은 아래에 있다.
5. 가로 방향으로 돌려 1~4를 다시 본다.
- **통과:** 1~5 모두 막힘 없이 되고, 글자가 잘리거나 겹치지 않는다.

## 3. 가정 카드 오해 여부
'조건이 바뀐다면' 카드의 수치(바람 절반, 점검 한 달, 수요 130, 전선 1칸 3 등)는 연습실 가정이다.
1. 학생이 카드 하나를 골라 한 줄 수정을 쓴 뒤, 교사가 묻는다: "이 카드의 숫자는 실제 통계인가요, 연습을 위한 가정인가요?" "실제로 풍속이 절반이 되면 풍력 발전량도 절반이 되나요?"
2. 손을 들게 하거나 쪽지로 받아 인원수만 센다.
- **통과:** 대부분(예: 3/4 이상)이 '가정'이라고 답하고, 풍력 질문에 "과제 규칙은 같게 세지만 실제는 훨씬 더 줄어든다"는 취지가 나온다. 미통과면 카드 문구의 '연습실 가정' 표시를 더 크게 하거나 수업 도입에서 한 번 짚는다.

## 사용자에게 정해 받을 것
- 세 가지를 모두 첫 시범 수업 전에 할지, 1·2만 먼저 할지.
- 화면 낭독기 확인을 Mac과 iPad 중 어느 쪽으로 할지(둘 다면 30분).
- 3번을 시범 수업 안에서 할지, 별도 소집단으로 할지.
