# 켄텍 창의성 면접 연습실

한국에너지공과대학교(KENTECH) 수시 일반전형의 창의성 면접을 연습하는 정적 웹앱입니다. 2022~2026학년도 기출 다섯 해를 각각 게임으로 옮겼고, 그 위에 형식이 바뀌어도 쓸 수 있는 세 습관을 연습하는 도구를 얹었습니다. 세 습관은 판단 기준을 먼저 말하기, 얻는 것과 잃는 것을 한 문장에 담기, 반문을 받은 뒤 답을 고치거나 유지하는 이유를 말하기입니다.

대학의 공식 자료가 아니라 학습용으로 만든 비공식 연습 도구입니다.

## 기출 게임

| 학년도 | 게임 | 핵심 조작 |
|---|---|---|
| 2022 | 미션 켄텍 | 10×10 지도에 발전소를 배치하고 세 마을에 전선 연결 |
| 2023 | 가람국 10년 계획 | 실행 항목 경로를 따라 10년 계획, 이웃국 대비 경계·위험 판정 |
| 2024 | 켄트로늄 정착 시뮬레이터 | 헥스 지도와 특별 아이템으로 탐험 계획, 계획에 맞춘 질문 |
| 2025 | 켄테시아 타임스 | 신문 4부 발행 순서 추론과 인과 근거 작성 |
| 2026 | 최우수 혁신기술 선정평가 | 홍보자료 4종 비판적 분석, 평가표 채점과 추천 |

모든 게임은 준비실, 면접실, 성찰 순서로 진행합니다. 준비실에서 자료를 조작하며 답을 만들고, 면접실에서 후속 질문에 말로 답한 뒤, 성찰에서 평가 기준으로 스스로 점검합니다.

## 연습 도구

- **판단 노트**: 준비실 위에 접혀 있습니다. 기준과 무게를 고르면 '기준 먼저' 문장을, 고른 것과 얻는 것·잃는 것을 적으면 한 문장을 만들어 보여 줍니다. 지난 연습에서 정한 목표를 다시 보여 줍니다.
- **반문 카드와 말해 보기**: 면접실 질문마다 연습용 반문을 받고, 답을 고칠지 유지할지와 그 이유를 적습니다. 말한 시간을 잽니다.
- **짝 면접**: 짝이 면접위원을 맡을 때 쓰는 화면입니다. 질문을 하나씩 보여 주고, 세 습관과 자료 인용을 관찰해 기록합니다.
- **짧은 판단 훈련장**(`#drill`): 겉모습이 다른 가상 과제 여섯 개에 같은 절차를 적용합니다. 수업용 과제지를 인쇄할 수 있습니다. 대학의 출제 경향을 예측한 문제가 아닙니다.
- **시간 설정**: 실전, 연장 1.5배, 직접 정하기, 시간 제한 없음 가운데 고릅니다. 교사는 `index.html?prep=15&answer=8`처럼 수업 주소로 시간을 정해 나눠 줄 수 있습니다. 이 경우에도 학생은 연장과 시간 제한 없음을 고를 수 있습니다.

## 창작 쟁점 게임

기출을 옮긴 게임이 아니라, 과학·사회 쟁점과 기술 정책을 다루도록 연습실이 새로 만든 게임입니다. 대학 출제와 무관하며, 배경과 수치는 가상입니다. 과학 원리는 실제를 따르고, 단순화한 모형은 화면과 성찰에서 무엇을 뺐는지 밝힙니다. 한 입장을 정답으로 두지 않고 지표를 나란히 보여 줍니다.

| 게임 | 다루는 쟁점 | 핵심 조작 |
|---|---|---|
| 섬 전력망 24시 | 에너지 전환, 저장, 피해 분배 | 배터리와 발전기의 하루 계획을 그려 세 날씨로 시험 |
| 시멘트 공장의 탄소 장부 | 산업 탈탄소, 탄소 포집, 장부 규칙 | 탄소 흐름의 밸브를 조절하고 장부상 감축과 물리적 배출 비교 |
| 변이 판독대 | 유전체 검사, 정보와 선택권 | 증거의 무게를 바꾸어 변이 카드 16장을 분류하고 알릴 범위 판단 |
| 심야 자율주행 셔틀 허가 심사 | 인공지능 규제, 인증, 이동권, 사고 책임 | 정지 경계 위에서 허용 속도와 시험 주행을 정하고 허가 판단 |
| 은여울강 가뭄 협상 | 물 배분, 하구 생태, 합의와 책임 | 배분안을 제안하고 역제안을 주고받으며 합의안 작성 |

창작 게임은 준비실에서 계획을 확정해야 결과와 면접 질문, 예시 판단이 열립니다. 성찰의 평가 기준은 공식 기준이 아니라 '연습용 평가 기준'입니다.

### 건설·운영 시뮬레이션 시안: 섬 전력망 건설(`#build`)

홈 첫 화면의 '섬 전력망 건설' 링크로 들어갑니다. 헥스 섬 지도에 태양광·풍력·디젤·배터리를 짓고 송전선을 이은 뒤, 정책 카드와 미션을 골라 1주·1달·3달을 빨리 돌려 봅니다. 결과로 마을별 정전 시간, 비용, CO₂, 주민 민원, 신문 제목, 면접관 질문 3개가 나옵니다. 위치를 바꿔 다시 지으며 더 나은 배치를 찾는 것이 목표입니다. 운영마다 「건설 일지」에 이유·예상 밖·얻고 잃은 것·다음을 적고, 일지 탭에서 회차를 비교하거나 활동지 글로 복사합니다(D-52).

지도는 두 가지입니다. 「연습 섬」은 설비 4종의 쉬운 첫 단계이고, 「평택」은 실제 지명 위의 20×15칸 지도에 시설 21곳(항만·산단·반도체 단지·크기별 도시·병원·소방서·역·정수장·농축산), 설비 10종(지붕 태양광·해상풍력·조력·소수력·바이오매스·외부 전력망 포함), 계절 선택(위도 36.99°N 일사량, 평택 평년 풍속), 실제 비율 수요(게임 1 MW ≈ 실제 100 MW), 「반도체 2라인 증설」 시나리오가 들어 있습니다. 숫자의 근거와 가정은 게임 안 ? 도움말의 '자료와 가정'에 있습니다(D-53). 아직 창작 게임 목록과 면접실 흐름에는 넣지 않은 시안입니다(D-50).

학생용 사용 설명은 [docs/student-manual.md](docs/student-manual.md)에 있습니다. 실제 면접 형식, 준비실·면접실·성찰에서 할 일, 게임별 공략 카드, 짝 면접, 4주 연습 계획을 담았습니다.

### 전력 리그: 멀티플레이와 혼자 하기(`#league`)

2~6팀이 도시 하나씩 맡아 전력망을 짓고 이웃과 전기를 거래합니다. 1턴은 1달이며 12/24/36달 가운데 고릅니다(기본 12달). 1월 재정지원금과 매달 세입·세출을 바탕으로 투자하고, 주민·기업의 이동과 집단별 지지율 변화를 봅니다(D-57). 기존 「계절 4라운드」도 선택할 수 있습니다.

교실에서는 진행자 화면을 프로젝터에, 팀 화면을 태블릿에 띄웁니다.

1. 교사가 「전력 리그」에서 팀 수·도시·게임 길이를 고르고 **새 방 만들기**를 누릅니다. 평택은 항상 포함합니다.
2. 팀은 방 코드나 참가 링크로 들어가 도시를 고릅니다. 같은 PC의 여러 탭에서는 「이 기기」, 서로 다른 태블릿에서는 「온라인(Supabase)」 연결을 씁니다. 온라인에는 프로젝트 주소와 공개 키가 필요하며, 교실 시험은 아직 남아 있습니다.
3. 교사가 달을 시작하면 팀은 설비·정책을 정하고 연계선을 협상한 뒤 **준비**를 누릅니다. 거래하려면 도시 안 전선을 노란 연결점까지 이어야 합니다. 교사가 **운영**하면 결과를 보고 일지를 쓴 뒤 다음 달로 넘어갑니다.

팀의 **도시 서랍**에는 주민·종사자·현금·지방채 한도·지지율, 여섯 집단의 만족, 지난달 돈과 이주 이유가 나옵니다. 계획 단계에 주민세·산업세·공공서비스·기업 유치 보조를 바꾸며, 기업 이전 조건도 비교합니다. 진행자는 **순위표**에서 주민·산업·재정 건전성·탄소·지지·전력 신뢰의 부분 점수를 보고, 광역 지도의 이주 화살표와 LNG·환율·수출·해운 지수를 함께 읽습니다. 현금을 쌓는 것 자체에는 점수를 주지 않으며, 점수용 지지율은 최근 12달 평균입니다.

혼자 연습하려면 로비의 **혼자 하기**에서 내 도시·참가 도시·게임 길이·컴퓨터 성향을 고릅니다(`#league/solo`). 신중·균형·공격의 세 성향은 같은 규칙 안에서 투자·발전 구성·정책·연계선 판단을 달리합니다(G). 네트워크 없이 한 탭에서 **준비** 버튼으로 진행하며, 새로고침 뒤 이어 할 수 있습니다. 기존 `#build`는 자유 건설 연습입니다.

면접 연습은 일지의 **우리 기준**에서 시작합니다. 점수 항목과 지킬 선을 고르고, 큰 결정 전에 선택적으로 결과를 예측합니다. 운영 뒤 예측과 결과를 비교하고 반문에 고치거나 유지할 이유를 적습니다. 끝에는 성찰·활동지 복사와 진행자 토의 카드, 가중치를 바꿔 순위를 비교하는 장치가 있습니다. 모두 연습용이며 대학 채점 기준은 아닙니다(G). 기준 항목·숫자·유지/바꿈은 같은 방 기기에 공유되고, 이유·일지·반문 답의 자유 서술은 입력한 기기에만 남습니다(D-59). 팀 순위의 일부 이름을 가리는 것은 화면 표시 방식입니다.

도시 이름은 현재 실제 지명을 쓰며 가상 이름으로 일괄 변경할 예정입니다(D-58). 시작 통계는 O*·G가 섞여 있고 시설 배치·정책 효과·점수 가중은 연습용 가정입니다. 이주 속도 ×4.8은 수업용 배속(G)으로 표시하며 실제 도시의 전망으로 읽지 않습니다. 근거 등급 O/O*/P/M/G와 생략한 요소는 [경제 명세](docs/ECON-SPEC.md)와 [자료·보정표](docs/ECON-DATA.md)에 있습니다. 사건의 실제 크기는 운영 뒤 공개하고, 철거는 30% 회수, 대학·연구소는 연구 → 실증 → 도입 규칙을 따릅니다(D-56).

리그 검사는 저장소 루트에서 실행합니다. 브라우저 검사는 기존 `tests/.venv`의 Playwright 환경을 씁니다. 먼저 `python3 tests/srv.py 9430 .`으로 로컬 서버를 띄우고 다른 터미널에서 실행합니다.

```bash
node tests/league/balance.js
tests/.venv/bin/python tests/league/econui.py http://127.0.0.1:9430/index.html
tests/.venv/bin/python tests/league/solo.py http://127.0.0.1:9430/index.html
tests/.venv/bin/python tests/league/ai-check.py http://127.0.0.1:9430/index.html
tests/.venv/bin/python tests/league/bots36.py http://127.0.0.1:9430/index.html --months 36
```

각각 밸런스 v1.2, 경제 화면, 혼자 하기 12달 완주, 컴퓨터 도시, 공통 건설 계획을 바탕으로 한 36달 전략 비교를 검사합니다. 컴퓨터 도시 검사는 `python3 tests/league/ai-check.py --node`로도 실행할 수 있습니다. 전체 결과는 [인계 문서](docs/HANDOFF-econ.md) §9에 총괄이 기입합니다.

### 화면 시안 v2: 게임 화면

창작 게임을 '웹 문서와 카드 목록'에서 '직접 조작하는 시뮬레이션 화면'으로 바꾸는 시안입니다. 계산 모형, 저장 형식, 판정, 기존 조작은 그대로 두고 화면 셸만 바꿨습니다. 장면은 게임 상태를 읽어 그리며, 사용자가 장면에서 직접 누른 조작만 게임의 기존 계획 함수로 전달합니다. 게임마다 고전 게임의 화면 양식을 오마주했습니다. 화면에는 원작 게임의 이름을 쓰지 않습니다.

| 게임 | 오마주한 화면 양식 | 장면에 드러나는 상태 |
|---|---|---|
| 섬 전력망 24시 | 헥스 지도 전략 게임(문명 시리즈): 도시 이름표, 다음 턴 버튼, 턴 보고, 퀘스트, 렌즈 | Canvas로 그린 로우폴리 3D 섬. 시간 구간별 빛, 발전원→계통→마을로 흐르는 전력(굵기 = MW), 디젤 연기, 배터리 잔량, 창문 불빛, 차단된 급전선 구역, 구름 날씨, 구간마다 바뀐 점을 알리는 보고 카드 |
| 시멘트 공장의 탄소 장부 | 90년대 등각 투영 도시 건설 게임(심시티 2000): 베벨 창, 예산 장부 | 시멘트 공장의 포집 설비, 연기, 이산화탄소 배관, 장부 표지판 |
| 변이 판독대 | 서류 심사 부스 게임(Papers, Please): 종이 서류, 도장 | 세 서류함의 카드 수, 증거 저울, 보고선·상담선 |
| 심야 자율주행 셔틀 허가 심사 | 80년대 아케이드 야간 주행 게임(아웃런, 나이트 드라이버) | 날씨별 도로, 허용 속도, 공개된 필요 감지 거리 범위 |
| 은여울강 가뭄 협상 | 90년대 역사 전략 게임(에이지 오브 엠파이어 II): 양피지 지도, 외교 창 | 저수지, 물 배분 수로, 하구, 협상 당사자의 깃발 |

섬 전력망 24시는 섬이 화면 전체를 차지하고, 상태 막대·도구 막대·패널이 그 위에 뜹니다. 계획 패널에 기존 준비실 화면이 그대로 들어 있습니다. 휴대폰과 세로 태블릿에서는 아래 메뉴와 아래 시트로 바뀝니다. 나머지 네 게임은 기존 문서 흐름(창 스크롤, 띠 아래 요약 띠)을 유지하고 준비실 위에 장면을 둡니다. 면접실과 성찰은 모든 게임에서 문서 화면입니다.

기출 게임 5종에도 같은 방식(문서 흐름 + 준비실 위 장면)으로 오마주 스킨을 입혔습니다. 보고서에서 옮긴 문항, 제시문, 지도, 데이터, 배치, 문구는 바꾸지 않았습니다. 장면은 학생이 고르거나 입력한 값과 화면에 이미 적힌 값만 그리며, 보고서의 예시 답안·예시 배치·정답 순서는 읽지 않습니다.

| 학년도 | 오마주한 화면 양식 | 장면에 드러나는 상태 |
|---|---|---|
| 2022 미션 켄텍 | 16비트 도시 건설 게임(심시티, SNES판): 위에서 본 타일 지도, 조언자 창 | 학생이 세운 발전소 4기, 마을 연결, 선택한 데이터 겹쳐 보기 |
| 2023 가람국 10년 계획 | 개척 길 여행 게임(오리건 트레일): 이정표, 연차 진행, 상태 지표 | 학생이 고른 10년 실행 항목, 누적 지수, 이웃 국가 대비 경계·위험 |
| 2024 켄트로늄 정착 시뮬레이터 | 90년대 후반 외계 행성 실시간 전략 게임(스타크래프트): 사령부, 미니맵, 자원 표시줄 | 고른 정착지 칸, 아이템별 모듈, 엔지니어 드론, 화면에 적힌 생산·소비량 |

2024 장면은 지도 모양을 게임 화면의 지도에서 읽습니다. 그래서 기출 충실도 수정(보고서 133칸 지도)이 합쳐져도 따로 고칠 필요가 없습니다. 다만 새로고침 직후 준비실을 거치지 않고 면접실로 바로 들어가면 내장 지도로 그립니다.

## 자료 출처와 한계

- 기출 문항, 제시문, 카드, 데이터, 예시 답안은 각 학년도 선행학습 영향평가 보고서에서 옮겼습니다. 그래프 수치는 원 그림의 눈금에 맞춰 근사했습니다. 보고서 원문과의 전체 대조는 아직 하지 않았습니다.
- 보고서에 공개되지 않은 부분은 새로 설계했고 화면에 '재구성'으로 표시했습니다. 2024학년도 시뮬레이션의 계산식이 그 예입니다.
- 반문 카드, 관찰 항목, 말 시작 예시, 연도별 기준 칩 같은 연습용 문장은 `practice-data.js` 한 곳에 모았습니다. 편집 검토는 이 파일에서 합니다.
- 입력한 내용은 이 브라우저의 localStorage에만 저장되며 밖으로 보내지 않습니다. 홈 화면의 '이 기기 기록 모두 지우기'로 지울 수 있습니다.

## 실행

빌드 단계가 없는 정적 파일입니다. 저장소 폴더에서 정적 서버를 띄우고 브라우저로 엽니다.

```bash
python3 -m http.server 8000
```

그다음 `http://127.0.0.1:8000/`을 엽니다.

## 검사

Playwright로 데스크톱·모바일(390px)과 라이트·다크 모드, 네 환경에서 모든 화면을 조작합니다. 단언 실패, 콘솔 오류, 페이지 오류, 가로 스크롤을 문제로 셉니다.

처음 한 번만 검사 환경을 만듭니다.

```bash
uv venv tests/.venv && uv pip install --python tests/.venv/bin/python playwright && tests/.venv/bin/playwright install chromium-headless-shell
```

전체 검사를 돌립니다. 결과는 `tests/results/`에 남습니다.

```bash
tests/run.sh
```

검사 이름은 `regression`(기존 다섯 게임 흐름), `base`, `screens`, `routine`, `probe`, `peer`, `drill`, `integration`, `originals`(창작 게임 공통)와 창작 게임 id(`s-island-grid` 등)입니다. 이름을 주면 그 검사만 돌립니다. 모든 JS 파일은 `node --check`로도 확인합니다.

창작 게임의 계산 모형은 브라우저 없이 따로 검산합니다. 명세의 검산표와 질문 분기를 게임 파일의 `KCP.games[id].model`로 다시 계산해 대조합니다.

```bash
for f in tests/model_*.mjs; do node "$f"; done
```
