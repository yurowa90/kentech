# 켄텍 창의성 면접 연습실

한국에너지공과대학교(KENTECH) 수시 일반전형의 창의성 면접을 연습하는 정적 웹앱입니다. 2022~2026학년도 기출 다섯 해를 각각 게임으로 옮겼고, 그 위에 형식이 바뀌어도 쓸 수 있는 세 습관을 연습하는 도구를 얹었습니다. 세 습관은 판단 기준을 먼저 말하기, 얻는 것과 잃는 것을 한 문장에 담기, 반문을 받은 뒤 답을 고치거나 유지하는 이유를 말하기입니다.

대학의 공식 자료가 아니라 학습용으로 만든 비공식 연습 도구입니다.

## 기출 게임

| 학년도 | 게임 | 핵심 조작 |
|---|---|---|
| 2022 | 미션 켄텍 | 10×10 지도에 발전소를 배치하고 세 마을에 전선 연결 |
| 2023 | 가람국 10년 계획 | 실행 항목 경로를 따라 10년 계획, 이웃국 대비 경계·위험 판정 |
| 2024 | 켄트로늄 정착 시뮬레이터 | 헥스 지도와 특별 아이템으로 탐험 계획, 계획에 맞춘 질문 |
| 2025 | 켄테시아 타임스 | 신문 4부 발행 순서 추론과 인과 근거 작성 |
| 2026 | 최우수 혁신기술 선정평가 | 홍보자료 4종 비판적 분석, 평가표 채점과 추천 |

모든 게임은 준비실, 면접실, 성찰 순서로 진행합니다. 준비실에서 자료를 조작하며 답을 만들고, 면접실에서 후속 질문에 말로 답한 뒤, 성찰에서 평가 기준으로 스스로 점검합니다.

## 연습 도구

- **판단 노트**: 준비실 위에 접혀 있습니다. 기준과 무게를 고르면 '기준 먼저' 문장을, 고른 것과 얻는 것·잃는 것을 적으면 한 문장을 만들어 보여 줍니다. 지난 연습에서 정한 목표를 다시 보여 줍니다.
- **반문 카드와 말해 보기**: 면접실 질문마다 연습용 반문을 받고, 답을 고칠지 유지할지와 그 이유를 적습니다. 말한 시간을 잽니다.
- **짝 면접**: 짝이 면접위원을 맡을 때 쓰는 화면입니다. 질문을 하나씩 보여 주고, 세 습관과 자료 인용을 관찰해 기록합니다.
- **짧은 판단 훈련장**(`#drill`): 겉모습이 다른 가상 과제 여섯 개에 같은 절차를 적용합니다. 수업용 과제지를 인쇄할 수 있습니다. 대학의 출제 경향을 예측한 문제가 아닙니다.
- **시간 설정**: 실전, 연장 1.5배, 직접 정하기, 시간 제한 없음 가운데 고릅니다. 교사는 `index.html?prep=15&answer=8`처럼 수업 주소로 시간을 정해 나눠 줄 수 있습니다. 이 경우에도 학생은 연장과 시간 제한 없음을 고를 수 있습니다.

연습실이 새로 만든 과학·사회 쟁점 게임 다섯 개를 `games/`에 추가하는 중입니다.

## 자료 출처와 한계

- 기출 문항, 제시문, 카드, 데이터, 예시 답안은 각 학년도 선행학습 영향평가 보고서에서 옮겼습니다. 그래프 수치는 원 그림의 눈금에 맞춰 근사했습니다. 보고서 원문과의 전체 대조는 아직 하지 않았습니다.
- 보고서에 공개되지 않은 부분은 새로 설계했고 화면에 '재구성'으로 표시했습니다. 2024학년도 시뮬레이션의 계산식이 그 예입니다.
- 반문 카드, 관찰 항목, 말 시작 예시, 연도별 기준 칩 같은 연습용 문장은 `practice-data.js` 한 곳에 모았습니다. 편집 검토는 이 파일에서 합니다.
- 입력한 내용은 이 브라우저의 localStorage에만 저장되며 밖으로 보내지 않습니다. 홈 화면의 '이 기기 기록 모두 지우기'로 지울 수 있습니다.

## 실행

빌드 단계가 없는 정적 파일입니다. 저장소 폴더에서 정적 서버를 띄우고 브라우저로 엽니다.

```bash
python3 -m http.server 8000
```

그다음 `http://127.0.0.1:8000/`을 엽니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 스크립트와 스타일 로드 순서 |
| `app.js` | 공통 엔진: 라우팅, 저장, 타이머, 면접실·성찰 화면, 확장 계약(이벤트와 화면 슬롯) |
| `data.js` | 연도별 메타데이터와 평가 기준 |
| `practice-data.js` | 연습용 문장 데이터 |
| `g2022.js`~`g2026.js` | 기출 게임 |
| `ext/` | 연습 도구 모듈(판단 노트, 반문 카드, 짝 면접, 훈련장) |
| `games/` | 창작 쟁점 게임 |
| `tests/` | 브라우저 검사 |

## 검사

Playwright로 데스크톱·모바일(390px)과 라이트·다크 모드, 네 환경에서 모든 화면을 조작합니다. 단언 실패, 콘솔 오류, 페이지 오류, 가로 스크롤을 문제로 셉니다.

처음 한 번만 검사 환경을 만듭니다.

```bash
uv venv tests/.venv && uv pip install --python tests/.venv/bin/python playwright && tests/.venv/bin/playwright install chromium-headless-shell
```

전체 검사를 돌립니다. 결과는 `tests/results/`에 남습니다.

```bash
tests/run.sh
```

검사 이름은 `regression`(기존 다섯 게임 흐름), `base`, `screens`, `routine`, `probe`, `peer`, `drill`, `integration`입니다. 이름을 주면 그 검사만 돌립니다. 모든 JS 파일은 `node --check`로도 확인합니다.
